# examples — 가온로보틱스 (가상 종목, 템플릿 §9)

`mindmap demo -o examples` 로 재생성된다. 숫자는 모두 임의값이다.

| 파일 | 내용 |
|---|---|
| `gaon_A.json` / `gaon_A.html` / `gaon_A.md` | 신규 투자 맵. ER 45.7%, 손익비 2.70 → BUY, 제안 비중 6.75% → 확정 5% |
| `gaon_B.json` / `gaon_B.html` | 보유 종목 맵 (2027-01-15). 🟡 — 비중 7.2% > 밴드 6.5%, 고평가(82%ile). 매트릭스 trim, 주가 +31% 중 멀티플 +23.6% |
| `gaon_B_summary.html` | 🟢 종목용 요약 뷰 (상태등 · 핵심 질문 · 논제 상태 · 결정 · 다음 확인일) |
| `gaon_C.json` / `gaon_C.html` | 포트폴리오 롤업. 순매도 2,200만 원 → 현금 10.2% |

HTML 은 자체 렌더러(중심에서 양쪽으로)라 인터넷 없이 열린다.
